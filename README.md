#Agrinho 2026
O objetivo desse site é informar o leitor sobre as formas de se implantar as tecnicas de Maneijo Integrado de Pragas. 
Para usa-lo deve-se escrolar para baicho e ou utilizar os botões no cabeçalho que sempre estará  na parte superior do site, bem como os dois botões da primeira pergunta implicita do site que te designarão para para as partes quecondizem com seu objetivos
Este projeto se justifica uma vez que essa é uma técnica  vital para alcançarmos um furturo mais sustentáel e os agricultores precisam saber disso
